# 应急安全智库 · 固定访问入口

本仓库是**公开**的 GitHub Pages 静态跳转页，只做一件事：把访客立即送到站点当前地址。

- 对外链接（永不变）：https://andyfly518.github.io/kb-link/
- 打开即 0 秒直达，无需点击、无需等待、无需二次确认
- 站点地址变化时，`sync-url.sh` 自动重写本页并推送，对外链接保持不变

## v7.4 整改（2026-11-15）

| 问题 | 整改 |
|---|---|
| 会员可自助跳过商家审核开通 | 关闭用户端自助开通，会员只能由商家后台核对收款后开通 |
| 会员可自行登录运营后台 | 前后台身份互斥，会员登录即撤销后台权限；页脚不再暴露后台入口 |
| 固定入口需二三次确认 | 跳转页改为 0 秒直达（meta refresh + 同步 location.replace），去掉 fetch / 延时 / 按钮 |

> 详细整改报告与验收结果见私有源码仓库 `safe-kb-source` 或
> WorkBuddy 资料库归档文档 `08_v7.4_业务红线与身份隔离整改.md`。
>
> 本仓库**不含任何密钥、令牌或用户数据**，请勿在此上传源码包。
